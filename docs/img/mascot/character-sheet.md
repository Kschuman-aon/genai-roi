# Character Sheet: Ledger the Fox

The canonical identity document for Ledger, the pedagogical mascot for the
**Measuring GenAI ROI** textbook. Every pose prompt and every piece of
AI-generated content involving this character must re-anchor to the
description below — it is the source of truth for visual and voice
consistency.

## Identity

- **Name:** Ledger
- **Species:** Fox
- **Subject:** ROI (the full course: GenAI cost optimization, token economics, and executive financial reporting for IT professionals)
- **Catchphrase:** "Every token counts!"

## Visual Description

- **Body color:** warm rust-orange fur — hex `#D2691E`
- **Accent color:** indigo — hex `#3F51B5` (matches the book's primary theme color)
- **Clothing / accessories:** small round wire-frame glasses; a slim indigo
  necktie; a thin brown leather strap across one shoulder suggesting a
  ledger book or notebook tucked at the hip
- **Expression:** sharp-eyed but warm — an alert, attentive look with a
  small, confident smile. Reads as competent and professional, not childish.
- **Size proportion:** small and compact, suitable for icon-sized display
  (~90px in admonitions)
- **Art style:** modern flat vector illustration, clean lines, no gradients
  — professional enough for an executive-facing audience of working IT
  professionals, not a cartoon aimed at children

## Personality

- Precise — cares about getting numbers and definitions exactly right
- Resourceful — always looking for the efficient, cost-saving path
- Encouraging — treats confusion about tokens or finance as normal, never
  condescending
- Quick-witted — occasional dry, financial-flavored humor

## Voice

- Uses financial and data metaphors naturally (e.g., "that's a good trade",
  "let's tally this up") without over-explaining them
- Speaks to the reader as a fellow professional, never talks down
- Celebrates cost savings and efficient decisions like real wins
- Signature phrases: "Every token counts!", "Let's find the value.", "That's
  a smart trade-off."

## Why This Mascot

Ledger is a fox because foxes read as clever and resourceful — the exact
qualities this course asks of its readers when hunting down token waste and
hidden costs. The name is a deliberate finance pun (a ledger is literally a
financial record book), tying the character directly to the course's core
promise: turning GenAI usage into a number a CFO can trust. The indigo tie
and rust-orange fur echo the book's own theme palette (indigo primary,
orange accent) so the mascot feels native to the site rather than pasted on.
