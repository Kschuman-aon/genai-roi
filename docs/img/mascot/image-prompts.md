# Ledger the Fox — AI Image Prompts

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

Each prompt below is fully self-contained — copy any single one into your
image generator without needing the others. All seven must match the
[character sheet](character-sheet.md) exactly: a modern flat vector fox
named Ledger, warm rust-orange fur (`#D2691E`), small round wire-frame
glasses, a slim indigo necktie (`#3F51B5`), and a thin brown leather strap
suggesting a ledger book at the hip. Ledger is the pedagogical mascot for
the *Measuring GenAI ROI* textbook — professional and sharp-eyed, not
cartoonish or childish, since the audience is working IT professionals.

Recommended generation size: 1024x1024, then resize down for use. After
saving each image, run the padding trimmer (see the main installer output
for the exact commands) — AI generators routinely leave excess transparent
padding that makes the mascot render too small at the book's 90px display
size.
