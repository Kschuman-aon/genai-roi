    List of MicroSims for Measuring GenAI ROI¶

    Interactive Micro Simulations to help students learn measuring genai roi fundamentals.

    • Anatomy of a Prompt

      Interactive p5.js MicroSim for anatomy of a prompt.

    • Autoscaling and Warm Pool Behavior Over a Traffic Day

      Interactive p5.js MicroSim for autoscaling and warm pool behavior over a traffic day.

    • Benefit Realization Calculator

      The learner will calculate the year 1 realized benefit and the three-year ROI of the running example from measured adoption, usage coverage, minutes saved, and rework data, to within $1 for dollar values and 0.1 percentage points for ROI.

    • Budget Burn Alert Simulator

      The learner will calculate the day on which each of four cost alerts (50%, 80%, 100% of budget, and month-end forecast) fires for a month with a runaway daily spend, to the exact day.

    • Byte Pair Encoding Step-Through

      Interactive p5.js MicroSim for byte pair encoding step-through.

    • Compute Utilization and Idle Cost Explorer

      Interactive Chart.js MicroSim for compute utilization and idle cost explorer.

    • Context Window Budget Allocation

      Interactive Chart.js MicroSim for context window budget allocation.

    • Cost Concept Classifier

      The learner will classify each of eight spending descriptions as capital expenditure, operating expenditure, sunk cost, or opportunity cost.

    • Cost Per Task Benchmark Explorer

      The learner will compare the cost per completed task of a small and a large model, including human review of rejected answers, and identify which is cheaper at four review costs.

    • Cross-Provider Token Efficiency Dashboard

      Interactive Chart.js MicroSim for cross-provider token efficiency dashboard.

    • Deployment Placement Sorter

      The learner will distinguish which of four placement approaches (single region, multi-region, edge, hybrid cloud) best fits each of eight workload descriptions, by matching the deciding requirement in each description.

    • Fixed Versus Variable Break-Even Calculator

      The learner will calculate the monthly request volume at which a fixed-cost server and a per-request API cost the same, to within 1,000 requests.

    • From Raw Text to Helpful Assistant

      Interactive Mermaid MicroSim for from raw text to helpful assistant.

    • Metric Matcher

      The learner will classify each of ten described situations under the one metric from a list of eight that the situation measures, with at least 8 of 10 correct on the first attempt.

    • Model Cascade Cost Calculator

      The learner will calculate the monthly cost of a small-model-first cascade for a stated pass rate and decide whether it is cheaper than sending every request to the large model.

    • Model Scale Across Five Years

      Interactive Chart.js MicroSim for model scale across five years.

    • NPV and Payback Calculator

      The learner will calculate the net present value of the running-example cash flows at a stated discount rate to within $5, and decide whether the investment should be accepted.

    • One-Time Training vs. Recurring Inference

      Interactive Chart.js MicroSim for one-time training vs. recurring inference.

    • Peak Capacity Planner

      The learner will calculate the number of inference servers needed for a stated peak request rate and utilization ceiling, and the monthly cost of provisioning for the peak around the clock, to the nearest whole server and dollar.

    • Per-Request Token Cost Calculator

      Interactive p5.js MicroSim for per-request token cost calculator.

    • Prompt A/B Test Decision Lab

      The learner will judge, from a 95% interval for the quality difference, whether to adopt, reject, or keep testing a shorter prompt variant against a 3-point quality tolerance.

    • Prompt Compression Before/After Comparator

      Interactive p5.js MicroSim for prompt compression before/after comparator.

    • Request Routing Flow

      The learner will explain which path through cache, small model, quality check, large model, and fallback model each of five example requests takes and what it costs.

    • Same Task, Three Prompting Strategies

      Interactive p5.js MicroSim for same task, three prompting strategies.

    • Self-Attention, Qualitatively

      Interactive p5.js MicroSim for self-attention, qualitatively.

    • Semantic Cache Threshold Explorer

      The learner will recommend the similarity threshold that gives the largest saving without exceeding a stated tolerance for wrong cached answers per 100,000 requests.

    • Sensitivity Tornado Ranker

      The learner will differentiate which of four input changes reduces the running-example NPV the most, by ranking them from most to least damaging, and will predict whether a combined change makes the NPV negative.

    • Serving Batch Size Tuner

      The learner will solve for the batch size that gives the lowest cost per million tokens while a 400-token response finishes within a stated latency limit and the batch fits in GPU memory.

    • Speed Versus Quality Check

      The learner will judge, for each of eight time-saving claims, whether the claim can be reported as stated or must be restated net of rework, using the rule that rework minutes above 25% of the claimed saving require restatement.

    • The AI Family Tree

      An interactive vis-network diagram showing how Artificial Intelligence, Machine Learning, Deep Learning, Neural Networks, Generative AI, Foundation Models, and Large Language Models nest inside one another.

    • The Batch-Size Trade-Off

      Interactive Chart.js MicroSim for the batch-size trade-off.

    • The GenAI Deployment Landscape

      Interactive vis-network MicroSim for the genai deployment landscape.

    • The RAG Pipeline

      Interactive Mermaid MicroSim for the rag pipeline.

    • Three Ways to Shrink a Model

      Interactive Chart.js MicroSim for three ways to shrink a model.

    • Token Budget Governance Workflow

      Interactive Mermaid MicroSim for token budget governance workflow.

    • Unit Cost Metrics Calculator

      The learner will calculate cost per transaction, cost per query, and cost per user from the running example's operating data, distinguishing fully loaded cost from fees only.

    • Where Should This Model Run?

      Interactive vis-network MicroSim for where should this model run?.
